星盘（西方占星本命盘）一周速成计划

目标：7 天、每天约 1 小时，从零到能独立看懂并写出自己本命盘的基础解读；终极目标是能给别人做基础星盘测算。 范围：现代占星本命盘解读。本文第三章补齐"整张盘"的基础字典（小行星/虚点、庙旺落陷、宫主星、相位格局等），为你给别人看盘打底；行运、合盘等动态占星放在第五章延伸。 前提：你需要精确的出生时间（精确到分钟）、出生日期、出生城市——差几分钟上升星座可能就变了，排盘前先问父母或查出生证明。

一、先搞懂：本命盘到底是什么

本命盘（Natal Chart）= 你出生那一刻，以你出生地为观测点，天空中太阳、月亮、行星落在黄道带上的"位置快照"。它由三样东西叠加而成：

  • 行星（Planets）：天上的"演员"，代表不同的心理能量与人生议题。
  • 星座（Signs）：演员的"性格 / 演法"，12 个，决定能量以什么风格展现。
  • 宫位（Houses）：人生被切分的"12 个剧场"，决定这些能量落在你生活的哪一块。

一句话记法：行星 = 谁在演，星座 = 怎么演，宫位 = 在哪演。

排盘工具（任选其一，第一天就用）： - 手机 APP：爱星盘（中文友好，免费够用） - 网页：爱星盘网页版（ixingpan.com，中文免费、功能全）；进阶可选 astro.com / astro-seek.com（英文、部分收费，新手暂不必用） - 排盘后你会得到一张圆图 + 一张"行星落在哪星座 / 哪宫位"的数据表，后面每天都对着手里的盘练。

落位原理：行星"落"在哪，到底是什么意思？

  • 你出生的那一刻，天上每颗行星都位于「黄道带」（一圈 360° 的虚拟天球带）的某个经度上。
  • 黄道带被均分成 12 段、每段 30°，对应 12 星座。行星的经度落在哪一段 → 我们就说它"落在某某星座"。例：太阳在黄道 120°–150° 之间 → 落在狮子座。
  • 同时，以你出生地的地平线为基准，把天球按"宫位系统"切成 12 块"宫"，每块管一块人生领域。行星落在哪块宫的区间 → 说它"落在第 X 宫"。
  • 一句话：落座 = 在黄道哪一段（怎么演）；落宫 = 在人生 12 宫哪一格（在哪演）。两者都由你的出生时间 + 出生地点唯一确定。
  • 排盘软件（爱星盘）就是替你算好这些角度，把结果画成圆图 + 数据表——你后面每天"对着手里的盘练"练的就是这些。
  • 看不懂先跳过，Day 1 排完盘再回看这一段，会一下子通了。

2. 守护星与"庙旺落陷"（星座的先天尊贵）

每颗行星"主管"一个或多个星座（守护关系）。行星落在自己守护的星座 / 擢升星座时能量最顺，落在相反位置则受限。这套叫先天尊贵（Dignity），是判断"这颗行星在盘里爽不爽"的核心。

  • 庙（Domicile / 入庙）：行星在自己守护的星座，能量自在、好发挥。
  • 旺（Exaltation / 擢升）：行星在该星座"状态最佳"，比庙更亮眼。
  • 落（Fall / 落陷）：行星在该星座能量被压制、别扭。
  • 陷（Detriment / 失势）：行星落在它守护星座的对面，能量最不顺。

  • 怎么用：看对方某行星落座，落在它"庙 / 旺"的星座 → 这块能量顺畅、是优势；落在"陷 / 落" → 这块需要多经营，但不等于坏。
  • 📍 去哪学：《当代占星研究》"尊贵与无力"章；或 👉 庙旺落陷 占星入门（B站搜索） 。

3. 宫主星与飞星（能量在盘里怎么流动）

前面学了"行星落在哪宫"。但行星还会"管"某个宫——因为每个宫头都有一个星座，那个星座的守护星就是这个宫的"宫主星"。

  • 宫主星：第 1 宫头是白羊 → 火星就是 1 宫主星；它落在哪、状态如何，会"染"上整个 1 宫的议题。
  • 飞星（Dispositor）：行星 A 落在某星座 → 该星座守护星 B 就是 A 的"接收者"，能量流向 B 所落的宫。连续追下去能画出一条能量链。
  • 举例：太阳落在天秤（7 宫头）→ 天秤守护星是金星 → 看金星落在哪宫，太阳的能量最终"落到"那宫的议题上。
  • 这一步是"从单点解读"升级到"看全盘联动"的关键，给别人看盘时用来串起叙事。

4. 命主星（Ascendant Ruler）= 全盘的钥匙

  • 命主星 = 上升星座的守护星（如上升白羊 → 命主星是火星）。
  • 它被视为"整张盘的总管"，它的落座、落宫、相位，决定这个人整体以什么方式展开人生。
  • 看盘第一抓手：先找命主星，再看它状态——这是专业解盘的标准起点。
  • 📍 去哪学：《当代占星研究》"宫主星与命主星"；视频 👉 宫位的解读逻辑·宫内星/宫主星/宫头星座（BV1g6v8eDEoi） 。

5. 相位进阶读法

前面学了五大主相位。进阶要看三件事：

  • 容许度（Orb）：两颗行星实际夹角与"标准角度"的误差。误差越小越强（如合相通常 8° 内算强）。爱星盘会标出每个相位的 orb 值。
  • 出相 / 入相（Applying / Separating）：行星是在"接近"这个角度（出相，能量正在形成）还是"离开"（入相，能量已释放）。出相更有"进行中"的感觉。
  • 相位格局（Aspect Patterns）：多颗行星连成的几何图形，是盘里的"大戏"：
格局 组成 含义
大三角 Grand Trine 3 颗互成 120° 天赋流畅，但易安逸不用
T 平方 T-Square 2 对分 + 1 四分 强张力点，逼人行动
大十字 Grand Cross 4 颗互成 90°/180° 极度紧张，能量拉满
上帝手指 Yod 2 六分 + 1 150° 特殊使命，绕路达成
风筝 Kite 大三角 + 1 对分 把天赋转化为突破
  • 📍 去哪学：《当代占星研究》"相位格局"；👉 相位格局 大三角 T平方（B站搜索） 。

6. 逆行行星（Retrograde）

  • 逆行是地球视角的"看起来倒退"，占星里表示这颗行星的能量内在化、延迟、需要回头处理。
  • 常见：水星逆行（沟通 / 出行易出状况，但也是复盘好时机）；金星逆行（关系 / 价值重估）；土星逆行（责任复盘）。
  • 盘里出生就逆行的行星（如某人本命水星逆行）：这类议题此人更偏向内省、反复琢磨，而非外放。
  • 澄清：逆行 ≠ "凶"，是能量换了一种运作方式。给别人看盘别吓人。
  • 📍 去哪学：👉 本命盘 逆行 怎么看（B站搜索） ；书《顺逆皆宜的人生》书名就点题。

7. 分布统计（一眼看性格基调）

排盘软件通常会给一张"元素 / 模式分布饼图"，这是快速抓性格侧重的利器：

  • 四元素分布：火多 → 行动派；土多 → 务实；风多 → 理性思考；水多 → 情绪敏感。某元素一颗都没有叫"缺 X"，该领域是此人的盲区 / 功课。
  • 三模式分布：基本多 → 爱开创；固定多 → 能坚持但固执；变动多 → 灵活但易飘。
  • 半球侧重：
  • 上半球（7–12 宫）多 → 外向、关注外界成就与关系；
  • 下半球（1–6 宫）多 → 内向、关注自我与日常；
  • 东半球（10–3 宫）多 → 主动、自己掌控；
  • 西半球（4–9 宫）多 → 被动、受外界影响大。
  • 给别人看盘时，先抛分布结论（"你是个火元素偏多、偏外向的人"），对方立刻有共鸣，再展开细节。

8. 截夺与空宫（进阶坑）

  • 截夺（Intercepted）：某星座整段被"关"在同一个宫里（没落在任何宫头），它的守护星能量被"封"在该宫议题内，需特别看。
  • 空宫（Empty House）：某宫里没有行星 → 不代表这领域"没内容"，看它的宫主星落哪、状态如何即可（宫主星替它发言）。
  • 这两点是新手最容易误读的地方：看到空宫别慌，看到截夺别漏。

9. 给别人测算的完整流程（实战框架）

把前面所有零件串成一次完整解读，推荐顺序：

  1. 收信息：准确出生年 / 月 / 日 / 时（到分钟）/ 城市——信息不准全盘作废。
  2. 看分布：元素 / 模式 / 半球 → 先给性格基调。
  3. 抓核心：命主星 → 日月升 → 四轴（ASC / MC / DSC / IC）。
  4. 过宫位：逐宫看哪宫有行星、群星（Stellium，3 颗以上同宫）在哪，那是此人的生命重心。
  5. 看相位：主要和谐 / 紧张相位 + 有无大格局（T 平方等）。
  6. 串叙事：用一句主线收束（如"你是个外在温和、内在要强、事业上渴望被认可的人"）。

  7. 给建议：基于紧张相位 / 落陷行星，指出可经营的课题，而非下定论。

  8. 📍 去哪学：综合《内在的天空》（叙事法）+《当代占星研究》（查表）+ 多练熟人的盘。

10. 测算伦理与沟通（给别人看盘必读）

  • 不恐吓：用"倾向 / 能量 / 课题"而非"注定 / 一定会"。占星是地图不是判决书。
  • 不越界：健康、重大财务、法律决定，建议对方找专业人士，不替人下结论。
  • 重赋能：解读落点放在"怎么用好这块能量 / 怎么修这块课题"，让对方看完更有力量。
  • 守隐私：别人的盘和解读不要外传。

小结：这一章是"整张盘"的基础字典。7 天主线让你看懂自己的盘；这一章让你有能力看懂并讲述别人的盘。两者结合，就是你能独立给别人做基础测算的底线知识。

五、一周后的延伸方向（可选）

本命盘是静态"出厂设置"。想继续可以学： - 行运 Transit：当下行星划过你本命盘，看"现在正发生什么"。 - 推运 Progressions / 太阳弧：看中长期人生阶段变化。 - 合盘 Synastry：两人盘叠加，看关系互动。 - 古典 vs 现代占星：两条路线解读口径不同，选自己舒服的深入。

学习方法建议：每天始终盯着自己的盘练，比背概念快得多。卡住就回到"行星怎么演、在哪演"这个底层框架，不要被术语吓住。
